# The Signal

Open index.html to preview. Open editor.html to add links.

Paste an article URL, optionally enter a headline, and click Add link. Source is filled from the domain; section defaults to World. You can change it in More options.

Copy & publish copies your complete edition and opens headlines.js in the ElMundoBizzaro/the-signal GitHub editor. Select all of that file, paste, and Commit changes. GitHub Pages publishes the updated file. This is not a direct authenticated publishing button: the GitHub commit step is still required.

Initial setup: upload all eight files to the root of a public GitHub repository. In Settings > Pages, choose Deploy from a branch, main, /(root), and Save.

All headlines are manual. There are no RSS feeds, scheduled updates, API keys, or paid services. Starter links point to publishers, not fabricated news stories.
